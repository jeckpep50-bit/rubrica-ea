# EA Conecta · Eight Academy

Portal de Recursos Institucionales del Departamento de Experiencias de Aprendizaje.

- `index.html`: el portal (inicio de sesión con la cuenta institucional): Huella de clases, Pedir un recurso, Trabajos de mis estudiantes y Banco de ideas.
- `config.js`: dirección del servidor (Apps Script) e ID de cliente de Google.

Este repositorio no contiene datos ni evidencias: todo vive en el Google Workspace del colegio y solo se entrega a cuentas autorizadas después de iniciar sesión.
