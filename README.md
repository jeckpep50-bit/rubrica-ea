# EA Conecta · Eight Academy

Portal de Recursos Institucionales del Departamento de Experiencias de Aprendizaje.

- `index.html`: el portal (inicio de sesión con la cuenta institucional): Huella de clases para docentes y evaluación de clases para evaluadores y directivos.
- `autorreflexion.html`: página personal del docente para responder su autorreflexión.
- `config.js`: dirección del servidor (Apps Script) e ID de cliente de Google.

Este repositorio no contiene datos, evidencias ni el texto de la rúbrica: todo vive en el Google Workspace del colegio y solo se entrega a cuentas autorizadas después de iniciar sesión.
